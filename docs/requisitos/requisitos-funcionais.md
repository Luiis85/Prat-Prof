# Requisitos Funcionais

## Sistema de Gestão de Eventos e Auditórios

Os requisitos funcionais abaixo foram definidos com base no escopo do projeto e serão analisados e validados pelo grupo.

| Código | Requisito Funcional |
|---|---|
| RF01 | O sistema deve permitir o acesso de usuários identificados. |
| RF02 | O sistema deve diferenciar os perfis Administrador/Organizador e Participante. |
| RF03 | O sistema deve permitir o cadastro de auditórios. |
| RF04 | O sistema deve permitir consultar a disponibilidade dos auditórios. |
| RF05 | O sistema deve considerar a capacidade do auditório na escolha do local. |
| RF06 | O sistema deve permitir criar, consultar, alterar e encerrar eventos. |
| RF07 | O sistema deve permitir consultar os eventos disponíveis. |
| RF08 | O sistema deve permitir realizar inscrições em eventos. |
| RF09 | O sistema deve permitir cancelar inscrições. |
| RF10 | O sistema deve permitir a entrada de participantes em fila de espera. |
| RF11 | O sistema deve promover participantes da fila quando uma vaga for liberada. |
| RF12 | O sistema deve permitir consultar a situação das inscrições. |
| RF13 | O sistema deve permitir realizar o check-in dos participantes. |
| RF14 | O sistema deve registrar a presença e o horário do check-in. |
| RF15 | O sistema deve impedir a utilização duplicada do identificador de check-in. |
| RF16 | O sistema deve gerar certificados para participantes com presença registrada. |
| RF17 | O sistema deve permitir o acesso aos certificados. |
| RF18 | O sistema deve permitir verificar a validade dos certificados por meio de um código único. |
| RF19 | O sistema deve permitir ao administrador acompanhar inscrições, vagas, fila de espera, presenças e certificados. |
