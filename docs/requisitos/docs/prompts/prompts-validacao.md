# Prompts utilizados na validação dos requisitos

## Prompt 01 — Validação dos requisitos funcionais

Analise a lista de requisitos funcionais do projeto "Sistema de Gestão de Eventos e Auditórios". Verifique se os requisitos estão claros, objetivos, testáveis e de acordo com o escopo definido para o sistema. Identifique requisitos duplicados, ambíguos ou que estejam fora do escopo. Não crie funcionalidades novas sem justificativa. Ao final, apresente sugestões de melhoria para os requisitos que apresentarem problemas.

## Resultado

A IA foi utilizada como ferramenta de apoio na análise dos requisitos. Após a análise, os integrantes do grupo deverão revisar e validar os requisitos antes de considerá-los definitivos.
